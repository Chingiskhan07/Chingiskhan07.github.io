## Objective

Understand the syntax and role of HTML; utilize basic and advanced HTML tags to build your first webpage; apply CSS for styling purposes; and publish the webpage on the internet via GitHub Pages.

## Part 1. Introduction to HTML

**Steps covered:** Step 0 – Step 4  
- HTML boilerplate (`<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`)  
- Headings `<h1>`–`<h3>`, paragraph `<p>`  
- Ordered list `<ol>` (hobbies) and unordered list `<ul>` (favorite websites)  
- Image `<img>` (my photo)  
- Two clickable links `<a>` (LinkedIn, Monopoly)  
- Button "Click Me"

## Part 2. Intermediate HTML

**Steps covered:** Step 5 – Step 8  
- Table with 3 columns: Subject / Day / Time (weekly schedule)  
- Two-column layout using table (Menu + Main content)  
- Emojis in a paragraph about mood (😎 😱 🤯)  
- Contact form: Name (text), Email (email), Favorite Color (color), Submit button

## Part 3. Introduction to CSS

**Steps covered:** Step 9 – Step 14  
- External CSS file `style.css` connected via `<link rel="stylesheet">`  
- Inline CSS (`style="color: #c1121f;"`)  
- Internal CSS inside `<style>` in `<head>` (`.internal-note`)  
- External CSS rules moved to `style.css`  
- Element selectors (`body`, `h1`, `p`), class selector (`.highlight`), ID selector (`#main-heading`)  
- Class `.highlight` applied to multiple elements

## Part 4. Intermediate CSS

**Steps covered:** Step 15 – Step 20  
- Favicon via `<link rel="icon" type="image/png" href="favicon.png">`  
- `<div>` grouping: `.header`, `.main-content`, `.footer`  
- Box model: padding, border, margin  
- CSS positioning: static, relative, absolute (inside `.position-area`)  
- CSS sizing: `px`, `%`, `em`, `rem` (`.sizing-demo`)  
- Float left / float right + clearfix

## Summary

The `index.html` was developed with all necessary HTML elements, linked `style.css`, included favicon, forms, tables, lists, and emojis. Inline, internal, and external CSS were used during practice. The process of using the box model (padding, border, and margin), positioning (static, relative, and absolute), and float & clear was explained. The website is hosted on GitHub Pages.
